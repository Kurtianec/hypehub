# Site Auditor

Локальное приложение для проверки публичной поверхности веб-сайта. Node.js 20+, без установки пакетов.

```bash
npm start
```

Откройте http://127.0.0.1:4317. Введите HTTPS-адрес и нажмите «Начать аудит». Сервер слушает только localhost; отчёты остаются в браузере и не сохраняются.

Проверяет HTTP-заголовки, CORS, cookies, доступность служебных путей, реакции GET/POST и один тестовый вход с фиктивными данными (если найдена стандартная форма). SQL-проверка сравнивает ответ на безопасный тестовый параметр и один SQL-подобный ввод; её результат лишь индикатор для ручной проверки. Инструмент не проверяет исходный код, авторизацию после входа, IDOR, реальную эксплуатацию SQLi и бизнес-логику. Запускайте его на своих сайтах или там, где вам разрешена проверка.

Защита от случайных запросов во внутреннюю сеть: адреса localhost, частные IP, внутренние имена и перенаправления туда блокируются. Нет перебора паролей и изменяющих запросов к произвольным путям.
