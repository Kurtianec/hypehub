SITE AUDITOR — версия для загрузки на сайт

1. Загрузите всю папку audit/ в корень сайта на хостинге с PHP 8.1+ и расширением cURL.
2. Откройте https://ваш-домен/audit/ и введите пароль, предоставленный вместе с архивом.
3. Введите адрес проверяемого HTTPS-сайта. Отчёт можно скачать в JSON.

Никаких команд на хостинге выполнять не требуется. Для Vercel Static / обычного
статического хостинга PHP не подходит: там серверный PHP-код не выполняется.

Запросы ограничены по времени и количеству, ответы с потенциально секретными
файлами не выводятся. Программа не сохраняет отчёты и пароли проверяемых сайтов.
Предназначена для сайтов, на проверку которых у вас есть разрешение.

Автоматический HTTP-аудит не доказывает отсутствие SQLi, XSS, IDOR или ошибок
контроля доступа. Эти проблемы требуют проверки исходников и тестовых учётных записей.
