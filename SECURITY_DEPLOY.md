# Простое обновление HypeHub

1. Сделайте резервную копию базы Neon.
2. Замените файлы старого проекта файлами из архива.
3. В GitHub Desktop нажмите **Commit to main**, затем **Push origin**.
4. Дождитесь завершения сборки в Vercel.

Во время сборки Vercel автоматически установит зависимости, обновит структуру существующей базы, зашифрует старые логины и пароли товаров, соберёт и опубликует сайт.

Дополнительные переменные добавлять не требуется: используется уже настроенная в Vercel переменная `DATABASE_URL`.

После обновления войдите в админку прежним паролем. При первом успешном входе он автоматически заменится в базе безопасным хешем. Затем откройте **Админка → Настройки → Безопасность**, задайте новый сложный пароль и сохраните.

Встроенная математическая CAPTCHA работает без Cloudflare и дополнительной настройки.

Важно: не меняйте `DATABASE_URL` после автоматического шифрования без предварительного переноса ключа. Она используется как основа ключа, пока отдельно не настроен `HYPEHUB_SECURITY_KEY`.
